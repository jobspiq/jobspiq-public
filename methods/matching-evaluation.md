# Matching evaluation

Full article (figures as of 12 October 2026): https://jobspiq.in/blog/why-keyword-search-fails-engineering-hiring

- A fixed set of 140 candidate–job pairs, each labelled by a person (3 = should alert, 2 = relevant, 1 = borderline, 0 = wrong), is re-scored every week against the live matching engine.
- 12 October 2026 run (117 pairs scored): 90% of shown jobs labelled at least borderline; 88% of alert-level matches labelled relevant; 14% of hidden jobs labelled relevant; Spearman correlation 0.60 (0.60–0.71 over the eight weekly runs since 24 August 2026).

Limits: 117 pairs can show a regression but are not a precise accuracy figure. No keyword-search baseline has been run, so no comparison is claimed.

Correction (12 October 2026): an earlier version showed "match accuracy" percentages and described the weighting of core skills incorrectly. They were removed.
